# Sakitoru v4 — Cloudflare серверийн хувилбар

2026-11-16. QPay, AI орчуулга холбогдоогүй.
Энэ багц нь сайт + Worker API + өгөгдлийн сангийн бүтэц + зураг хадгалалтын холбоос юм.
Бодит Cloudflare бүртгэлд хараахан байрлуулаагүй, жинхэнэ банкны данс тохируулаагүй.

## Нэмсэн ажиллагаа
- Нэвтрэх нэр, нууц үгээр бүртгүүлэх/нэвтрэх; сэргээх кодоор нууц үг сэргээх.
- HttpOnly/Secure cookie session; серверээс админ эрх шалгана.
- Нэвтрэх нэр ашиглана, имэйлийн баталгаажуулалт/имэйлээр сэргээх үйлчилгээ байхгүй.
- Дэлгэцийн нэр, төрсөн огнооны профайл; XP/урилга.
- VIP хугацаа сонгож захиалга үүсгэнэ. Админ бодит дансны орлогыг шалгаж батална.
- Админы банк, IBAN/данс, хүлээн авагчийн нэрийн тохиргоо.
- Хэрэглэгчийн ID, түр хаах/сэргээх (сесс цуцална).
- Бүтээлийн каталог D1-д, PNG/JPEG/WebP зураг R2-д хадгалагдана.
- Secret бүлэг болон байршуулсан зургийг сервер VIP/насны эрхээр хамгаална.
- Хавчуурга, уншсан байрлал тухайн браузерт хэвээр хадгалагдана.

## Баталгаажуулалт
- npm test: 25 тест амжилттай.
- npm run build: JavaScript синтакс шалгалт амжилттай.
- Wrangler 4.162.0 deploy --dry-run: Worker + assets багц үүссэн.
- Workerd/Miniflare: бүртгэл, нууц үг хэшлэх, сесс, D1-ээс account авах амжилттай.
- Браузерт нүүр, бүртгэлийн форм, төслийн төлөв нээгдсэн.
- Браузерийн бүртгэл/админ бүх дарааллыг гараар дуусгаж шалгаагүй.
- Бодит банкны шилжүүлэг болон нийтэд нээлттэй Cloudflare байршуулалт шалгаагүй.

## Cloudflare-д байрлуулах
Энэ нь дан статик Pages ZIP биш. Worker + D1 + R2 шаардлагатай.
Node.js 24 орчим хувилбар бүхий компьютер дээр багцын хавтаснаас:

    npm ci
    npx wrangler login
    npx wrangler d1 create sakitoru

Буцсан database_id утгыг wrangler.jsonc дахь REPLACE_WITH_D1_DATABASE_ID оронд бичнэ.
Хуучин төсөл/санг дарж бичихгүй; ижил нэр байвал нэрийг ялгаж тохируулна.

    npx wrangler d1 migrations apply sakitoru --remote
    npx wrangler r2 bucket create sakitoru-media
    npx wrangler deploy

R2 нь хувийн bucket байна. r2.dev public URL нээхгүй.
Үйлчилгээ төлбөрийн бүртгэл шаардаж байвал автоматаар зөвшөөрөхгүй.

## Эзэмшигчийн эрх ба банк
1. Нийтлэгдсэн сайт дээр өөрөө бүртгүүлж сэргээх кодоо хувийн газар хадгална.
2. Дэлгэцийн нэр, төрсөн огнооны профайлаа бөглөнө.
3. Миний бүртгэл хэсэгт харагдах өөрийн хэрэглэгчийн ID-г авна.
4. wrangler.jsonc-ийн vars.ADMIN_USER_ID-д зөвхөн өөрийн ID-г тохируулж дахин deploy хийнэ.
   Анх бүртгүүлсэн хүнийг автоматаар админ болгохгүй.
5. Нэвтрээд Удирдлага → VIP төлбөр: банк, данс/IBAN, хүлээн авагчийн нэрээ хадгална.
6. Өөр уншигчийн бүртгэлээр VIP хүсэлт үүсгэнэ. Банкны орлогыг үнэхээр шалгасны
   дараа админ 'Банкны хуулгаас төлбөр орсныг шалгасан' гэдгийг тэмдэглэж VIP нээнэ.

## Хязгаар ба арчилгаа
- Нэг зураг 8 MiB хүртэл; PNG/JPEG/WebP. Secret бүлгийн зургийг upload хийнэ.
- Каталогийн нэг удаагийн хадгалалт 900 KB хүртэл метадата. Том каталогт дараа нь
  бүтээл/бүлгээр хуваасан хүснэгт рүү шилжүүлэх шаардлагатай.
- Upload амжилттай ч каталог хадгалалт тасарвал ашиглаагүй зураг R2-д үлдэж болно.
- Нууц үг болон сэргээх кодоо хоёуланг алдвал автомат сэргэлт боломжгүй.
- Хуучин GPT Sites хэрэглэгч, VIP, бүтээлүүд автоматаар шилжээгүй. Энэ бол шинэ
  Cloudflare өгөгдлийн сангийн хувилбар; хуучин өгөгдлийг тусад нь экспорт/шилжүүлнэ.
- Зар зөвхөн батлагдсан ad unit тохируулбал ажиллана; бодит зарын үйлчилгээ шинээр холбогдоогүй.
- Cloudflare дээр бодит хэрэглээг нээхээс өмнө данс, админ ID, storage bindings,
  VIP урсгал болон нэвтрэлтийн CPU хэрэглээг бодит орчинд шалгана. Төлбөртэй plan эхлүүлээгүй.

## Хөгжүүлэлт
    npm test
    npm run build
    npx wrangler deploy --dry-run --outdir dist/cloudflare
    node scripts/check-runtime.mjs

npm run dev нь зөвхөн локал туршилтын сервер. Түр өгөгдлийн сан, туршилтын админтай;
тэр админ, туршилтын данс үйлдвэрлэлийн Worker-д орохгүй. Worker-ийн entry point:
worker/cloudflare.mjs. Scripts доторх dev серверийг production-д ашиглахгүй.
